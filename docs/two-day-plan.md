# Two-day execution plan

## Day 1 — Get the pipeline running

| Time | Task | Deliverable |
|---|---|---|
| 0:00–1:00 | Earth Engine setup and AOI polygon | Study area |
| 1:00–3:00 | Sentinel-1/Sentinel-2 composites | Valid feature stacks |
| 3:00–5:00 | WorldCover samples and forest RF | Forest maps |
| 5:00–6:30 | Historical change detection | Loss maps and hectares |
| 6:30–8:00 | Risk RF and temporal validation | Risk map and metrics |

## Day 2 — Validate and submit

| Time | Task | Deliverable |
|---|---|---|
| 0:00–2:00 | Test a second polygon and troubleshoot | Reusable demonstration |
| 2:00–3:30 | Export GeoTIFFs and statistics | Output files |
| 3:30–5:30 | Write methodology and results | Report |
| 5:30–7:00 | Prepare figures and slides | Presentation |
| 7:00–8:00 | Rehearse demonstration and check limitations | Final submission |

## Priority order

If processing takes longer than expected, prioritize:
1. A valid forest classification.
2. At least one historical change map.
3. A risk model with temporal validation.
4. Exports and documentation.

Do not spend the two days building a complex web UI before the analytical pipeline works.
